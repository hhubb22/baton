# 桌面客户端行为规格

Status: approved
Owner: 待确认
Basis: 2026-10-27 桌面端能力讨论；[设备接入行为规格](../device-setup/PRODUCT.md#桌面客户端) DS-15～DS-23；[发布与升级行为规格](../release/PRODUCT.md) RL-05、RL-10～RL-14。

## Summary

桌面客户端加载中心网页，网页能做的事在客户端里都能做。在此基础上，客户端提供浏览器做不到的本机能力：从中心获取新版本并自动完成设备数据迁移，窗口隐藏时也能弹系统通知，托盘显示运行中的工作，在本机打开工作目录、选择本机目录，查看本机 batond 的诊断信息。接入、常驻、托盘基础菜单和退出行为沿用 DS-15～DS-22。

## 范围与概念

| 概念 | 含义 |
|---|---|
| 中心网页 | 客户端窗口加载的已保存中心的页面，随中心发布，不打进客户端安装包 |
| 桌面能力 | 客户端向中心网页开放的一项本机功能，带名称和版本，网页按声明决定是否显示对应入口 |
| 本机设备 | 客户端内置 batond 所注册的设备；由外部服务运行时（DS-19）也算本机设备 |
| 客户端更新 | 中心托管的、与中心兼容的客户端版本；客户端只从已保存中心获取更新 |

本期支持 macOS arm64 与 Windows x64，安装包不签名、不公证。不在本期范围：macOS 静默替换应用（需要 Developer ID 签名）、把网页打进安装包、离线查看、Linux 桌面客户端、同时连接多个中心、手机。

## Behavior

### 桌面能力

- DC-01：客户端向中心网页声明它支持的桌面能力及版本。网页只为已声明的能力显示入口；在普通浏览器中或客户端未声明某项能力时，对应入口不出现，网页的其他功能照常可用。网页遇到不认识的能力时忽略。
- DC-02：只有来自已保存中心地址的主页面可以调用桌面能力，规则与 DS-17 相同。其他站点、子框架和本地说明页调用时被拒绝，客户端不执行任何动作。
- DC-03：每项桌面能力只执行一个具体动作，例如「打开这个 Thread 的工作目录」。客户端不向网页提供执行任意命令、读写任意文件或列出任意目录的能力。网页传入的参数只用来指明对象，本机路径由客户端从本机 batond 取得。

### 更新与数据迁移

- DC-04：客户端启动后及运行期间每 6 小时，从已保存中心查询它托管的客户端版本。中心托管的版本与当前版本不同时，托盘和窗口显示有新版本，附版本号。按 RL-05，客户端版本须与中心一致，更新总是升到中心托管的版本；正式发布（GA）前不允许客户端停留在旧版本继续连接。客户端不从中心以外的来源获取更新。
- DC-05：中心以版本不兼容拒绝本机设备时（DS-22、DS-23），客户端显示原因，并直接提供上一条中的更新入口，员工无需到设备页手动下载。
- DC-06：员工选择更新后，客户端先让本机设备进入升级准备（RL-10），显示正在等待的工作和结果补报，等待方式和取消规则同 RL-11。员工可以在这里停止等待中的工作，或取消更新；取消后设备恢复正常执行。
- DC-07：升级就绪后，Windows 客户端下载新版本，安装并重新启动，员工不需要其他操作。macOS 客户端下载新版本安装包并打开，提示员工把新版本拖入「应用程序」替换旧版，然后退出旧版本；替换期间设备保持升级暂停。
- DC-08：新版本首次启动时，发现设备数据来自旧版本，就自动执行数据迁移（RL-07、RL-14），完成后启动 batond，设备恢复执行。迁移期间窗口和托盘显示迁移进度，客户端不重启 batond。迁移失败时显示失败位置和原因，设备保持升级暂停，提供重试和打开日志目录，不自动回退或重建数据。
- DC-09：员工没有经过 DC-06 就直接替换了应用时，新版本首次启动由自己的 batond 发起升级准备，按 RL-12 的就绪条件检查本机：仍有独立 Worker、Runtime 或其他进程在运行时，显示等待原因，等它们退出后再迁移。客户端不强制结束这些进程。
- DC-10：更新过程中的任一步被中断（客户端退出、系统重启、下载失败）后，再次启动客户端会显示当前所处阶段并从该阶段继续，或提供重试。已下载但校验值不符的安装包被丢弃，不会安装。

### 系统通知

- DC-11：客户端运行期间（包括窗口隐藏在托盘时），员工的 Thread 或 Project 出现以下情况会弹出系统通知：Agent 提出问题或请求确认，Turn 结束，Turn 失败或异常停止，本机设备被拒绝连接。通知标题写 Thread 或 Project 名称，正文说明发生了什么。
- DC-12：员工正在已聚焦的窗口里查看某个 Thread 时，这个 Thread 的事件不弹通知。同一事件只通知一次；网页重连或重新加载后，不会为已通知过的事件重复弹出。
- DC-13：点击通知后显示并聚焦窗口，打开对应的 Thread 或 Project；对应对象已删除或已归档时，打开列表并说明原因。
- DC-14：托盘菜单提供「通知」开关，默认开启，选择保存在本机。操作系统关闭了客户端的通知权限时，开关旁说明通知被系统禁用，并提供打开系统通知设置的入口。

### 托盘运行状态

- DC-15：托盘在 DS-22 的设备状态之外，显示员工当前正在运行的 Thread 数，以及等待员工回复的数量（问题和确认请求）。统计范围与 DC-11 的通知相同，包括员工在所有设备上的 Thread。等待回复的数量大于 0 时，托盘图标显示标记。
- DC-16：托盘菜单列出等待回复的 Thread，最多 5 个，点击后打开对应 Thread。

### 本机打开与目录选择

- DC-17：Thread 运行在本机设备上时，网页在设备·目录行末尾提供本机打开图标，可选择「在访达中显示」（Windows 为「在资源管理器中显示」）和「用编辑器打开」。Project 页中的本机 Thread 行提供同样入口。前者在系统文件管理器中打开该 Thread 的工作目录；后者用员工在客户端设置里选的编辑器打开，没有设置时用系统为文件夹关联的默认程序。客户端只接收 Thread ID 和打开方式，由 batond 返回可信工作目录。目录在本机已不存在时提示目录不存在，不创建目录。
- DC-18：其他设备上的 Thread 不显示本机打开入口。Project 保持跨设备调度，不绑定设备或工作目录；Project 页的本机入口来自其中运行于本机的 Thread，不为 Project 本身提供目录入口。
- DC-19：新建 Thread 选择工作目录时，如果目标设备是本机设备，网页提供「选择本机目录」，弹出系统目录选择框。员工取消时不改变当前选择。选出的目录仍按中心对该设备设置的可用目录范围校验，范围之外的目录显示原因并拒绝。新建 Project 不选择设备或目录，也不提供本机目录选择入口。

### 本机诊断

- DC-20：在客户端中打开本机设备的详情页时，额外显示 batond 进程状态、最近一次退出的原因与时间、当前客户端与 batond 的版本、升级或迁移所处阶段，并提供重启 batond 和打开日志目录。设备由外部服务运行时（DS-19），重启入口不出现，说明由外部服务管理。
- DC-21：员工可以从详情页复制一份诊断摘要，内容包括版本、平台、设备状态、最近的退出原因和日志末尾 200 行。摘要不含注册凭据、模型凭据或部署配置里的私密内容。

## 验收

| 场景 | 设置与操作 | 必须观察到的结果 | 关联 |
|---|---|---|---|
| 能力声明 | 同一中心网页分别在浏览器、当前版本客户端和缺少某项能力的旧版客户端中打开 | 浏览器中没有桌面入口；旧版客户端只缺对应入口；其他功能不受影响 | DC-01 |
| 调用来源 | 其他站点页面、中心页面内的子框架、本地说明页分别调用桌面能力 | 全部被拒绝，本机没有任何动作 | DC-02、DC-03 |
| Windows 更新 | 中心托管新版本；本机有运行中的 Turn 和排队输入；选择更新 | 先显示等待当前 Turn；就绪后自动安装重启；迁移后设备在线，排队输入只发送一次 | DC-04、DC-06～DC-08 |
| macOS 更新 | 同上，在 macOS 上按提示替换应用 | 替换前设备保持升级暂停；新版本首次启动自动迁移，设备恢复执行 | DC-07、DC-08 |
| 版本拒绝 | 中心升级后用旧版客户端连接 | 显示不兼容原因和更新入口，按入口更新后重新连接 | DC-05 |
| 直接替换 | 不经更新入口直接替换应用，独立 Worker 仍在运行 | 新版本显示等待原因，Worker 退出后才迁移 | DC-09 |
| 中断恢复 | 在等待、下载、迁移各阶段退出客户端后重新启动；篡改已下载安装包 | 从原阶段继续或可重试；校验不符的包不安装；迁移失败保持暂停并显示原因 | DC-08、DC-10 |
| 通知 | 窗口隐藏时 Agent 提问；窗口聚焦在该 Thread 时 Turn 结束；网页重新加载 | 隐藏时弹通知，点击打开该 Thread；聚焦查看时不弹；重新加载不重复弹 | DC-11～DC-13 |
| 通知开关 | 托盘关闭通知；系统禁用客户端通知 | 关闭后不再弹出；系统禁用时显示说明和设置入口 | DC-14 |
| 托盘状态 | 两个 Thread 运行，一个等待回复 | 托盘显示 2 个运行、1 个等待并带标记；菜单点击打开该 Thread | DC-15、DC-16 |
| 本机打开 | Thread 详情和 Project 页分别查看本机 Thread、其他设备 Thread；删除本机工作目录后尝试打开 | 本机 Thread 的设备·目录行末尾提供文件管理器和编辑器打开入口；其他设备 Thread 没有入口；Project 本身没有目录入口；目录不存在时提示且不创建 | DC-17、DC-18 |
| 目录选择 | 新建 Thread 目标为本机时选择范围内目录、范围外目录、取消；打开新建 Project | 范围内目录被选中；范围外显示原因；取消不改变选择；新建 Project 不选择设备或目录，没有本机目录选择入口 | DC-19 |
| 诊断 | 结束 batond 进程后查看详情页；复制诊断摘要；外部服务运行时查看 | 显示退出原因与时间；摘要不含凭据；外部服务时没有重启入口 | DC-20、DC-21 |

自动化验收使用本地中心、本地 CA 与进程替身，不访问外部服务。系统通知、目录选择框、文件管理器、安装替换和登录启动在 macOS arm64 与 Windows x64 上手动验证，未测的平台如实记录。网页界面改动先完成设计稿，再修改 `web/src`。
