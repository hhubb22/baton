# Agent 对话时间线原型

`agent-timeline.html` 是独立交互原型，使用示例数据，不连接中心或调用 Agent。正式 Web 组件没有引用该文件。

从仓库根目录启动：

```sh
python3 -m http.server 5180 --bind 127.0.0.1 --directory .impeccable/mocks
```

打开 `http://127.0.0.1:5180/agent-timeline.html`。文件也可直接在浏览器中打开；剪贴板功能受浏览器本地文件权限限制。

## 选定方向

采用 ChatGPT Chat 模式的布局：左侧导航、居中聊天正文、底部同宽输入框。聊天区无外框，助手回复无气泡，用户消息靠右；项目概览默认关闭，由标题栏按钮打开浮层。回复内部继续使用留白分组。

标题、关联对象和状态提示不使用装饰圆点。状态用明确文字表达，层级由留白、字重与文字颜色区分；已有状态文字时，不再添加彩色圆点重复表达。

展开过程只展示有用信息：命令与结果合为一行，空输出不增加结果折叠区；关联对话直接展示可点击名称，不重复添加安排说明和分组标题。设备与 Agent 信息保留在对话详情中。有诊断价值的失败输出仍可展开。

默认打开选定方向。可以使用 `?theme=dark` 直接打开深色主题。`agent-timeline-detail.css` 提供交互基础，`agent-chat-layout.css` 定义当前聊天布局。顶部工具条仅供原型评审使用。

## 排版与状态

图标使用 Phosphor Regular，SVG 路径取自项目安装的 `@phosphor-icons/react`。聊天使用 ChatCircleText，文件夹使用 FolderSimple，收件箱使用 Tray，复制使用 CopySimple；其余操作使用同系列。保留 16px 尺寸和 24px 图标槽位。Phosphor 使用 MIT 许可，见 https://github.com/phosphor-icons/react/blob/master/LICENSE。

| 项目 | 规则 |
| --- | --- |
| 阅读列 | 正文与输入框最大宽度均为 768px，在聊天区域居中 |
| 图标与文字 | 图标 16px；正文不为图标预留缩进，子对话引用采用图标加文字 |
| 正文 | 16px、1.75 行高；相邻段落间距 16px；窄屏正文 15px |
| 过程摘要 | 默认仅显示“处理了 12 秒”等简短摘要与右侧展开箭头；下方用一条细线与正文分开 |
| 过程详情 | 步骤、命令结果和关联对话默认收起，点击摘要展开；子对话标题 14px |
| 元信息 | 11px，使用弱文字色；正常完成状态不在引用列表重复展示 |
| 组内间距 | 摘要到正文 12px，正文到产物 16px |
| 回复操作 | 正文下方常显 30px 图标按钮，保留可访问名称和悬停提示，隐藏时间戳 |
| 回复组 | 组后留白 36px |
| 过程详情 | 步骤行高至少 28px；详情与步骤文字对齐，过程区域最多 288px、输出详情最多 230px |
| 待处理事项 | 正文同列，操作按钮紧随问题，无分隔线、独立卡片或状态圆点 |
| 输入框 | 底部固定，单行起步，随输入增长；圆角 28px，发送按钮位于右下角 |
| 断线 | 保留正文，在该回复内显示连接提示和对应重试入口 |

顶部“查看对齐线”显示正文起点，仅用于评审。标题栏状态可定位到当前进度或待处理事项。

## 交互

第二段执行过程取自 `web/src/data/http/projects.test.ts` 中 `keeps failed tools and command output without inventing completion facts` 的本地夹具，展示 `nodes.exec` 和 `threads.create` 的原始返回；这是测试数据，不是线上会话。Project 的真实映射见 `web/src/data/http/projects.ts`：仅提供工具名、输入、输出与调用状态。界面不自动归纳测试数量、故障原因或失败摘要，调用完成不等于任务验证通过。Thread 的上游事件另见 `packages/protocol/src/thread.ts` 和 `web/src/app/ActivityStep.tsx`，不与 Project 过程混用。

- 切换运行中、等待决定、已完成、连接中断；切换不自动收起用户已展开的过程摘要。
- 展开过程摘要及命令结果。
- 点击子对话打开详情，关闭按钮或 Escape 返回。
- 回答待处理事项；决定仅保留在当前原型中。
- 复制回复、输入并发送示例消息。
- 切换浅深色、窄面板，或重置内容。

原型沿用 Baton 的中性背景、文字与边框颜色。正式组件接入时需保留稳定回复身份、过程展开状态、确定性排序和后台刷新失败保留内容的行为。本阶段只细化独立原型，尚未修改正式组件或产品行为规格。
