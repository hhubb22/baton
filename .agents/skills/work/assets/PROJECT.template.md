## 任务与工单管理（轻量化原则）

- **日常开发默认不走工单**：小修复、局部重构、补测试或单次会话可闭环的改动，直接在对话中确认并完成代码提交，无需创建或查询外部工单。
- **跨会话大特性或待办看板**（按需配置外部工单系统）：
  - 工单工具 / 归属：<如 GitHub Issues / Plane / Linear 等，及对应项目标识>
  - **粗粒度切片**：跨天大特性控制在 3～5 张垂直切片工单，不拆碎单。
  - **极简正文与关单**：工单正文 ≤ 10 行（仅作指向 `specs/` 的轻量索引）；完成后置为完成并附一行 Commit SHA 结论。
