# 示例：展示配置动作与实际动作

Status: draft
Owner: 示例作者
Basis: 虚构的规则查询功能，仅用于示范写法，不描述 PICOS 或任何 SDK 的现状。

## Summary

管理员查询一条规则时，需要区分“希望设备执行的动作”和“设备当前报告的动作”。否则即使规则数量正确，也无法发现动作不一致。

## Behavior

- R-01：查询结果分别提供配置动作与实际动作；两者不同时都保留，不合并为一个 action。
- R-02：实际动作读取失败或平台不支持读取时，显示 unknown 和原因；不能用配置值代替实际读取结果。
- R-03：结果标注读取时间，避免把过去的成功读取表示成当前状态；精度和批量一致性要求另行确认。

## Open questions

目标平台是否支持读取全部相关动作尚未确认。这决定 R-01 的平台支持范围，不能仅凭现有配置接口推断。
