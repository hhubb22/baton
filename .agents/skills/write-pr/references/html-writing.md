# HTML 审核说明

页面服务于当前审核者需要理解的改动。先确定他需要判断什么，再选择展示方式。

| 改动 | 可选展示方式 |
|---|---|
| 行为修复 | 触发条件、修改前后结果和实际测试 |
| 跨模块或状态流转 | 调用关系、状态图或时序图，突出变化的路径 |
| 重构 | 职责和调用关系的前后对照，附行为验证 |
| 界面修改 | 同一条件下的截图与交互变化 |
| 数据迁移 | 数据格式变化、兼容期和回退后的处理 |

图示只保留真实存在且与问题相关的对象。代码片段引用文件位置和差异基线，省略部分明确标注。长 diff 可以折叠，解释放在相关片段附近；不要为了文件逐项解说而复制全部 diff。

页面模板提供可调整的起点。删除无内容的栏目和对应导航，替换全部占位符，按改动重新组织图示与代码。所展示的 HTML、代码和日志先进行文本转义，避免把代码内容当成页面标签执行。

默认生成一个独立 HTML 文件，内嵌 CSS，图示可用 SVG。折叠使用原生 details/summary；交互只有能帮助判断时才增加。不要为了渲染引入远端字体、图表 CDN 或网络服务。外部证据链接与页面依赖分开处理；附件打包时保持路径可解析。

内容的已确认、待验证和审查状态用文字表达，颜色只是辅助。保留清楚的标题、段落、代码对照和键盘可用的导航；SVG 提供 title 或邻近说明。设置窄屏布局与打印样式，长代码在代码区域内滚动。

打开生成文件，至少检查正常桌面宽度和约 390px 窄屏：无正文裁切、导航指向存在的栏目、图中标签可读、代码保持格式、证据链接和附件可用。打印预览在交付需要打印时检查。无法打开的私有链接记录访问限制；源码检查通过只说明源码检查本身。

标题描述实际改动。成品里只放审核材料，制作过程和渲染限制放在交付说明中。
