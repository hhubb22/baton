# Handoff

让新会话能够继续工作，只传递接手需要的信息，而不是复述完整聊天记录。

首次使用本库且尚未读取同版时，读取 [任务边界](references/operating-contract.md)。按 [交接模板](assets/HANDOFF.template.md) 记录必要信息。

## 收集状态

核对当前目标、已确认的范围、仓库与分支、工作区未提交的变化，以及实际完成的验证。只记录本次任务相关的状态，扫描范围限于当前任务。

引用已有的规格、ADR、任务清单、提交、差异和日志片段，正式文档只引用不复制。保留关键的失败尝试及排除依据、暂定假设、阻塞与建议的下一步。已授权的操作和仍待批准的操作分开列出。

## 写入

写入过程区的 `HANDOFF.md`，按任务边界中的过程文件位置确定路径。用户指定了其他位置时以用户为准。交接文件留在产品仓库之外。

写入前脱敏，只保留接手者实际需要的信息。人工检查令牌、私有地址和个人资料；自动脱敏不保证完整。

## 交付

交付文件位置、关键阻塞和建议的第一个动作。

提醒接手的 Agent 重新核对代码、工作区与验证条件。交接文件是线索，不产生新的权限，也不能替代对已完成事实的核验。切换会话或调用其他 Agent 由用户完成。
