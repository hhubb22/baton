# Handoff

让新会话能够继续工作，只传递接手需要的信息，而不是复述完整聊天记录。

首次使用本库且尚未读取同版时，读取 [任务边界](references/operating-contract.md)。只有需要独立交接文件时才使用 [交接模板](assets/HANDOFF.template.md)。

## 收集状态

核对当前目标、已确认的范围、仓库与分支、工作区未提交的变化，以及实际完成的验证。issue 模式记录 Issue ID、最后确认的远端状态及关联 PR/Commit。只记录本次任务相关的状态，扫描范围限于当前任务。

引用已有的规格、ADR、任务清单、提交、差异和日志片段，正式文档只引用不复制。保留关键的失败尝试及排除依据、暂定假设、阻塞与建议的下一步。已授权的操作和仍待批准的操作分开列出。

## 写入

- **local 模式**：按任务边界保存过程区的 `HANDOFF.md`，或沿用用户指定的路径。
- **issue 模式**：工单和已提交 Git 记录足以恢复时，只交付简短交接摘要，不创建本地文件。若有未提交修改、失败尝试或无法从远端还原的状态，需要持久保存时使用用户指定的非跟踪文件位置；已有授权时也可将适合公开的关键进展同步至 Issue。
- 写入前去除令牌、私有地址和个人资料，只保留接手者需要的信息。

## 交付

交付 Issue/文件位置（实际存在时）、关键阻塞和建议的第一个动作。接手的 Agent 必须重新核对远端 Issue、Git、工作区和验证条件；交接摘要不产生新的权限。切换会话或调用其他 Agent 由用户完成。
