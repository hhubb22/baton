# To questionnaire

把当前缺少的事实或决定交给有能力回答的人，避免让用户猜答案。

首次使用本库且尚未读取同版时，读取 [任务边界](references/operating-contract.md)。文档使用 [模板](assets/QUESTIONNAIRE.template.md)。

从上下文确定接收人的角色和希望得到的结果。只有无法推断、且会改变问法的信息才询问用户，例如接收对象或用途。已有答案和 Agent 能自己调查的事实不再提问。

先整理已知事实和证据，再列出真正需要对方回答的缺口。每个问题只问一件事，附上必要背景、可定位的依据，以及不同答案对本次工作的影响。建议答案标明是建议，避免诱导对方确认未经验证的事实。

重要问题排在前面，按主题适量分组，保留回答位置。允许对方部分回答、回答"未知"或"需要实验"。期限、接收人、已批准的决定和工作量以实际信息为准，未知时留空。

保存到过程区的 `questions-<topic>.md`，项目有约定目录时沿用，并报告位置。用户只要文字时直接输出。

发送邮件、消息或创建工单需要用户已有明确授权；没有授权时交付问卷即可。
